أدوات MR Solver

دليل استخدام واجهة MR Solver لحل الكابتشا مباشرة من خارج الموقع.

المفتاح والرابط الأساسي

يرسل المفتاح في الترويسة Authorization: Bearer <API_KEY> أو في جسم الطلب api_key.

endpoints
GET /v1/balance — رصيد الحساب (balance_cp ÷ 100 = النقاط).
POST /v1/solve — يحل كابتشا حساب واحد وينتظر حتى 90 ثانية.
POST /v1/captcha — يضيف حساب للطابور (rejoin tool).
GET /v1/me — بيانات الحساب.
أمثلة (curl)
# رصيد الحساب
curl https://api.zapzonex.net/v1/balance \
  -H "Authorization: Bearer 22b12d4b2efe0cf3.4370bfd721b26b1d1ec51e74d1e45899"
# حل كابتشا حساب واحد (ينتظر حتى 90s)
curl -X POST https://api.zapzonex.net/v1/solve \
  -H "Authorization: Bearer 22b12d4b2efe0cf3.4370bfd721b26b1d1ec51e74d1e45899" \
  -H "Content-Type: application/json" \
  -d '{"cookie":"_|WARNING:-abc...","placeId":"2753915549","username":"user1"}'
# أولوية Premium (تكلفة مضاعفة x2)
curl -X POST "https://api.zapzonex.net/v1/solve?priority=premium" \
  -H "Authorization: Bearer 22b12d4b2efe0cf3.4370bfd721b26b1d1ec51e74d1e45899" \
  -H "Content-Type: application/json" \
  -d '{"cookie":"_|WARNING:-abc...","placeId":"2753915549","username":"user1"}'
حالات الرد (status)
OK CAPTCHA_SUCCESS — تم الحل (يُخصم).
OK NO_CAPTCHA — لا يوجد كابتشا (يُتخطى بدون خصم).
RETRY CAPTCHA_FAILED / SOLVER_ERROR / SERVER_BUSY — فشل قابل لإعادة المحاولة.
FATAL INVALID_COOKIES / INSUFFICIENT_BALANCE / INVALID_SOLVER_KEY / MISSING_API_KEY / MISSING_PARAMS — خطأ نهائي.

كل الردود HTTP 200 حتى الأخطاء النهائية — تحقق من الحقل status.

التسعير

يُخصم المبلغ لكل حساب يتم حله فعلياً. الحد الأدنى في الموقع 30 حساب = 2.5 ريال. خيار Premium يضاعف التكلفة (x2) ويقدّم الطلب في قائمة الانتظار.
